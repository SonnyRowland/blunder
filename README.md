# Blunder

Blunder is a chess engine written in C. Motivation for this project comes from being bad at real-life chess.

## Features

- Universal Chess Interface (UCI)
- Perft verified move generation
- Iterative Deepening Depth First Search (iddfs)
- Alpha-Beta Pruning
- Move ordering with a Most Valuable Victim, Least Valuable Attacker (MVV-LVA) heuristic

## Repository structure

```
.
├── bench.md        // Benchmark performed after any major feature
├── build           // Build artefacts
├── include
├── src
│ ├── bench.c       // Benchmarks build
│ ├── board.c       // Represents board, board state, piece representation
│ ├── display.c     // Prints debug info to stdout
│ ├── eval.c        // Evaluates position
│ ├── fen.c         // Parses Forsyth-Edwards Notation strings
│ ├── main.c        // Runs game loop
│ ├── move.c        // Handles movement and parses Long Algebraic Notation
│ ├── movegen.c     // Generates legal moves, handles move ordering
│ ├── movesearch.c  // Performs iddfs + alpha-beta on move tree generated by movegen.c
│ ├── perft.c       // Helps verify correctness of move generation
│ ├── timemanager.c // Deals with game clock
│ └── uci.c         // Allows for interface with frontend via Universal Chess Interface
├── tests           // Unit tests
├── vendor          // third-party tools (Unity test framework files)
├── Makefile
└── README.md
```

## Usage instructions

Clone the repository from https://github.com/SonnyRowland/blunder

```bash
git clone https://github.com/SonnyRowland/blunder
```

Navigate into the directory, and build the project with `make`

```bash
cd blunder
make
```

You can then launch the engine by running `./build/artefacts/blunder`. The engine launches immediately into the UCI interface

Try feeding it the following commands in order: `uci`, `isready`, `position startpos`, `go movetime 1000`.

Whilst developing, I used [cutechess](https://cutechess.com/) frontend to play against blunder

## Performance

Search efficiency and speed are tracked in [bench.md](bench.md). Run
`./build/artefacts/blunder bench`
to benchmark the current build.

## Testing

Unit tests implemented with the Unity framework can be found in [tests](tests). Run `make test` to run all unit tests
